# Sales-Analysis-Dashboard-

An exploratory data analysis project using Python, Pandas, NumPy, and Plotly to inspect e-commerce sales, calculate KPIs, and build four interactive visualizations.

## Project contents
- `Internship.ipynb` — polished analysis notebook and interactive charts
- `sales_dataset.csv` — dataset supplied with the project
-  `requirements.txt` — Python dependencies

## Run the project
1. Download or clone this repository.
2. Keep `Internship.ipynb` and `sales_dataset.csv` in the same folder.
3. Install dependencies: `pip install -r requirements.txt`
4. Open the notebook in Jupyter, or upload both files to Google Colab.
5. Run all cells in order.

## Included analysis
- Dataset structure and quality checks
- Sales KPIs
- Daily revenue trend
- Revenue by product category
- Revenue distribution by region
- Revenue by payment method and category
- Data-driven findings, business questions, and limitations
